# 🌸 75 Hard Sticky Note Tracker

An interactive, pink-gradient sticky note simulator designed for tracking the 75 Hard Challenge.

## ✨ Features
- **75 Pink Gradient Sticky Notes**: Visual progression from light pink to deep magenta.
- **Custom Goal Checklist**: Pre-configured for daily routines (Bible Study, Workout, Reading, Spanish Practice, etc.).
- **Strict 75 Hard Rule Engine**: Missing any single item resets progress back to Day 1.
- **Custom Goal Customization**: Add, remove, or edit your personal daily goals at any time.
